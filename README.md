# CV Analyzer Frontend

Фронтенд для сервиса анализа резюме. Приложение помогает загрузить резюме, передать данные на сервер, дождаться анализа и посмотреть рекомендации в удобном формате.

## О проекте

Это интерфейс для пользователя, который хочет быстро проверить своё резюме перед откликом на вакансию. В приложении предусмотрены несколько сценариев работы:

* загрузка резюме в формате **PDF** или **DOCX**;
* ручное заполнение данных о резюме;
* добавление ссылки или текста вакансии;
* просмотр результата анализа по вкладкам;
* поддержка сопроводительного письма;
* отображение прогресса прохождения шагов.

## Как работает приложение

1. Пользователь открывает главную страницу и начинает проверку резюме.
2. На экране загрузки резюме можно выбрать файл или ввести данные вручную.
3. После отправки фронтенд отправляет данные в backend API.
4. Далее пользователь переходит к шагу с вакансией: можно вставить ссылку или добавить текст.
5. После запуска анализа приложение сохраняет `analysisId` и переходит на страницу результатов.
6. Страница результатов опрашивает сервер с интервалом и показывает данные, когда анализ готов.
7. Результаты разбиты на понятные категории: структура, технологии, релевантность и другие рекомендации.

## Технологии

Проект собран на современном фронтенд-стеке:

* **React 19** — построение интерфейса;
* **Vite** — быстрая сборка и запуск проекта;
* **React Router** — маршрутизация между экранами приложения;
* **Redux Toolkit** и **React Redux** — хранение состояния и работа с асинхронными запросами;
* **Chakra UI** — базовые UI-компоненты и визуальная консистентность;
* **SCSS** — стилизация компонентов и страниц;
* **react-markdown** — отображение ответа сервера в формате Markdown;
* **normalize.css** — выравнивание базовых стилей между браузерами;
* **react-icons** — иконки;
* **next-themes** — поддержка темизации;
* **ESLint** — контроль качества кода.

## Основные экраны

* **Главная страница** — знакомит пользователя с сервисом и объясняет принцип работы.
* **Загрузка резюме** — загрузка файла PDF/DOCX или ручной ввод данных.
* **Загрузка вакансии** — вставка ссылки или текста вакансии.
* **Загрузка сопроводительного письма** — отдельный шаг для анализа cover letter.
* **Результаты** — отображение анализа с переключением между разделами.
* **Ошибка** — обработка некорректных состояний и ошибок сервера.

## Ключевые компоненты

* **Dropzone** — drag-and-drop загрузка файлов с проверкой допустимых форматов.
* **ManualFields** — ручной ввод данных о резюме.
* **TextArea** — ввод текста вакансии или сопроводительного письма.
* **ProgressBar** — индикатор текущего шага.
* **Header** — верхняя часть интерфейса.

## Работа с API

Фронтенд ожидает адрес backend API через переменную окружения:

```bash
VITE_API_URL=
```

Запросы используются для:

* загрузки резюме;
* отправки данных, введённых вручную;
* запуска анализа;
* получения результата по `analysisId`.

## Асинхронная логика

Для отправки данных и получения результата используется Redux Toolkit async-thunk подход.

* сначала загружается резюме;
* затем создаётся запрос на анализ;
* после этого страница результатов опрашивает сервер каждые несколько секунд;
* как только ответ готов, данные отображаются в интерфейсе.

## Для кого этот проект

Этот интерфейс подойдёт для сервиса, который помогает:

* оценить качество резюме до отправки работодателю;
* проверить структуру и полноту данных;
* сопоставить резюме с вакансией;
* получить рекомендации по улучшению текста и содержания.

## Идея проекта

Главная цель фронтенда — сделать процесс проверки резюме простым и понятным: пользователь проходит шаги последовательно, а результат получает в аккуратном и читаемом виде.
